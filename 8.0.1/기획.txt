#점진적 조건
damage_taken = 받은 피해
kills_made = 킬 수
time_in_melee = 근접전
time_active_relative_to_duration = 시간 비례 
nearby_all_deaths = 죽은 수
nearby_allied_deaths = 아군 죽은 수
nearby_enemy_deaths = 적군 죽은 수

Intensity Type -> 증가/감소 조건
linear_multiplier = 선형 증가
inverse_linear_multiplier = 선형 감소

# 활성 조건
범위 내 x 있음 = allies_in_intercept_range
범위 내에 아군 없음 = cannot_find_allies_in_intercept_range
범위 내에 적군 없음 = cannot_find_enemies_in_intercept_range
범위 내 적군 있음 = enemies_in_intercept_range
근접전 중 = engaged_in_melee / out_of_melee
부대 활력 관련 = fatigue_is_below_active
체력 %이상 = health_above_10%
체력 %이하 = health_below_25%
생명력 보충 한계 도달 = hp_replenish_cap_reached
난동 관련 = is_not_rampaging / is_rampaging
근접전 패배중 = losing_melee_combat
사기 관련 = morale_is_broken_or_lower
? 이동 중 = moving
이동 중이 아닐 때 = not_moving
